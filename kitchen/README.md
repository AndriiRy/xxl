# Конфигуратор кухни

Открыть `kitchen/index.html` в браузере (без сервера и установки, всё локально; проект и библиотека сохраняются в браузере).

## Процесс
1. **Fusion 360** → моделируете только стены. Имена тел: `Стена…`, `Парапет…`, `Окно…`, `Дверь…`, `Вода…`, `Канализация…`, `Газ…`, `Розетка…`, `Вытяжка…`, `Колонна…`.
   Запустить `fusion/export_walls.py` (Utilities → Add-Ins → Scripts) → `walls.json`.
2. **Конфигуратор** → «Стены из Fusion…» (или вкладка «Стены» — можно создать комнату-заготовку без Fusion).
3. Из **библиотеки** перетащить модуль на план: он сам встанет к ближайшей стене (спиной), прилипает к стенам и соседям. Параметры (ширина, высота, глубина, полки, двери, ящики) — справа. `R` — поворот, `Del` — удалить, `Alt` при перетаскивании — без прилипания.
4. **Спецификация**: материалы, деталировка с кромкой, присадка (эскиз каждой детали с отверстиями), сборка. Экспорт: CSV для раскроя, JSON для Fusion (`fusion/import_parts.py` строит детали обратно в Fusion), печать/PDF.

## Эркер / 8-угольный парапет
- Стены передаются контуром (нижняя грань тела), поэтому наклонные участки эркера — точно. Парапет — тело `Парапет…` до подоконника, над ним `Окно…`, выше `Стена…` (перемычка).
- Без Fusion: вкладка «Стены» → «Эркер ½ восьмиугольника» (ширина проёма, глубина, высота парапета).
- Шкафы встают спиной к любой грани под любым углом; повороты ⟳90°/⟳45°, Shift+R — 45°.
- **Наружный излом** (стены уходят от комнаты, 225°): модуль «Угловая вставка эркера (скос)» — бросить у угла, сам встанет по биссектрисе и возьмёт угол излома. Треугольные дно/крышка — фигурные детали с координатами вершин.
- **Внутренний излом** (135°, внутри эркера): шкаф прижимается так, чтобы фасады соседей сошлись углами (отступ (D+tf)·tg(угол/2) от вершины), за ними — пустой треугольник.
- **«Столешницы автоматически»** (библиотека): по каждому ряду нижних шкафов у стены — столешница, торцы у изломов подрезаны (+угол/2 наружный, −угол/2 внутренний), стыки сходятся.
- Проверки: пересечения со стенами/соседями под любым углом; предупреждение, если изделие у окна выше подоконника (напр. столешница 858 > парапет 850).

## Библиотека — свои модули
В библиотеке ✎ — редактор: параметры, переменные, детали (бокс x/y/z + размеры формулами), фурнитура, шаги сборки. Живой 3D-предпросмотр. «⧉» — копия существующего модуля как основа. Экспорт/импорт библиотеки одним JSON.

Переменные формул: параметры модуля, `t` (корпус), `tf` (фасад), `tb` (ХДФ), `tt` (столешница), `gap`, `plinth`, `baseH`, `wallBottom`, `wallH`, `tallH`, `i`/`n` (номер/число экземпляров детали), функции `min max round floor ceil abs sqrt`, `?:`, сравнения.
Система координат модуля: x — вправо (вид спереди), y — вглубь (0 = передняя плоскость корпуса, D = стена), z — вверх. Фасады в y ∈ [−tf, 0]. Обязательные `W`, `D` (параметр или переменная).
Деталь: бокс x/y/z + размеры, `поворот z°` (вокруг угла x,y) или `Контур` «x,y; x,y; …» — фигурная пластина (столешница, треугольник). Модуль: «Габарит» — свой контур на плане (первое ребро — фронт), «в наружный угол» — привязка к излому стен. Функции в градусах: `sind cosd tand`.

## Ограничения MVP
- Нет L-угловых шкафов 90° (карусель/глухой), вырезов под мойку/варочную, сплошного цоколя, чертежей фасадов.
- Повёрнутые и фигурные детали — без автоприсадки (крепёж уголками, указан в фурнитуре).
- 3D — упрощённый (без z-буфера), возможны артефакты перекрытия граней.
- Присадка: конфирматы, полкодержатели, чашки и планки петель; направляющие ящиков — только комплектом в фурнитуре.
- Скрипты Fusion не тестировались в самом Fusion (нет доступа) — проверьте на копии файла.
