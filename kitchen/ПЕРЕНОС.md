# Перенос: телефон → компьютер (конфигуратор кухни)

## 1. Как продолжить на компьютере
- Эта же сессия Claude: https://claude.ai/code/session_016JYUnLiqyznTpCjh3y7Xw6 (claude.ai/code → список сессий). Вся переписка и контекст сохраняются.
- Если открываете **новую** сессию — первым сообщением: «Продолжаем конфигуратор кухни, прочитай kitchen/ПЕРЕНОС.md и kitchen/README.md».
- Код: репозиторий `andriiry/xxl`, ветка `claude/kitchen-project-options-l42yuw`, папка `kitchen/`.
- Запуск: открыть `kitchen/index.html` в браузере (без установки). Скачать ветку: GitHub → ветка → Code → Download ZIP. После слияния в `main` и при включённом GitHub Pages — `https://andriiry.github.io/xxl/kitchen/`.

## 2. Перенос данных (проект, стены, свои модули, настройки)
Данные хранятся **в браузере устройства**, сами на компьютер не попадают:
1. На телефоне: «Настройки» → «Скачать всё» → файл `kitchen-backup-ГГГГ-ММ-ДД.json`.
2. На компьютере: «Настройки» → «Загрузить всё» → выбрать файл.
3. Или положить файл в репозиторий `kitchen/backup/` — тогда он будет доступен в сессии.

## 3. Что прислать завтра
- Программы **XILOG3** (`.xxl`) фронтов (RIO и др.) + описания фрез → в `kitchen/fronts/` (по папке на модель фронта). В репозитории уже есть просмотрщик Xilog (`xxl.html`) — его парсер подключу к фасадам для визуализации фрезеровки.
- Скан **Twindo**: сессия не может открыть twindo.com (сеть окружения). Варианты: экспорт из приложения в DXF / OBJ / USDZ→OBJ и положить в `kitchen/scans/`; либо разрешить хост `twindo.com` в настройках сети окружения.
- Проверить высоты задних стенок Antaro (см. п.5) и ваши длины направляющих.

## 5. Сделано
- План / 3D / спецификация; стены из Fusion (контуры), RoomPlan JSON, OBJ, **DXF**; стены по длинам и углам; эркер; балки и скосы потолка.
- Модули: нижний с дверцами, **под угол (косые боки)**, **ящики Antaro**, **под духовку + ящик**, **под мойку (ящик/двери, Servo-drive)**, **карго**, **посудомойка (фасад)**, **колонна под холодильник** (ниша, разделённый фасад, антресоль, вентиляция), **верхний над вытяжкой**, верхний, пенал, пенал под скос, пенал с вырезом под балку, столешница с подрезкой торцов, бленда.
- Редактор модулей: параметры, формулы, детали в плоскостях xy/xz/yz, **конструктор фасадов** (секции снизу вверх: ящик / дверь / ниша / открытая → фасады, ящики Antaro, перегородки, фурнитура), мастер каркаса (дно между боков / бока на дне, царги / крышка, задняя внутри / в паз / накладная), каталог фурнитуры Blum.
- Спецификация в мм: материалы, фурнитура, деталировка с кромкой, присадка (конфирматы, полкодержатели, петли), фигурные детали с вершинами, **развёртки стен с размерами**, чертежи корпусов (спереди/сбоку), CSV для раскроя, JSON → Fusion.
- Интерфейс RU / PL.
- Перенос «Скачать всё / Загрузить всё».

## 6. Не сделано / следующий шаг
1. Фронты RIO и фрезеровка из XILOG3 (ждёт файлов).
2. 3D-конструктор с перетаскиванием элементов на «куб» (сейчас — конструктор секций и мастер по клику).
3. Высоты задних стенок Antaro заданы ориентировочно (N 52, M 68, K 100, D 167) — **сверить с каталогом Blum**.
4. Шкаф для завтрака с Blum Revego uno, L-угловые шкафы 90°, вырезы в столешнице под мойку/индукцию, чертёж фасадов с фрезеровкой, оптимизация раскроя листов.
5. Скрипты Fusion (`kitchen/fusion/*.py`) не проверены в самом Fusion — проверить на копии файла.
