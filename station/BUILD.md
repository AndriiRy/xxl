# Бюджетная станция замеров (самосборка, тросиковый привод)

## Состав
- `cad/station.scad` — параметрическая модель; `cad/*.stl` — готовые детали (NEMA17).
  Под 28BYJ-48: `MOTOR = "byj";` и перерендерить `openscad -D 'part="base"' -o base.stl station.scad` (и `arm`).
- `firmware/station/station.ino` — Arduino **Uno + CNC Shield v3**, 2×NEMA17 (V на 28BYJ-48 — только проба). Библиотека AccelStepper.
- `pi/station.py` — Raspberry Pi 3/4: замеры, скан, JSON, DXF. `pi/scan2dxf.py` — обработка.

## Печать (PETG, сопло 0,4, слой 0,2, 4 периметра, 6 верх/низ, гироид 40 %)
| Деталь | Масса | Ориентация |
|---|---|---|
| hz_drum | ~310 г | плоскостью вниз; канавку не поддерживать |
| base | ~145 г | плоскостью вниз |
| v_drum | ~90 г | плоскостью вниз |
| arm | ~55 г | лапой вниз |
| laser_plate | ~8 г | плоскостью вниз |
Посадки 608 (Ø22,15) сначала напечатать тестовым кольцом; при тугой — `B_OD = 22.25`.

## Механика
1. Hz: болт М8×50 головкой в шестигранник снизу основания → гайка сверху основания (затянуть) →
   шайба → барабан с 2×608 → шайба → гайка с лёгким преднатягом (вращение без качания, без заеданий) → контргайка.
2. Мотор Hz снизу основания (4×М3×8), вал вверх, вал на уровне канавки.
   На оба вала — латунная трубка 6×0,5 мм длиной 10 мм на эпоксидку/Loctite 638 (закрывает лыску вала: без неё ошибка до 0,2°).
3. Тросик PE 0,5 мм: конец 1 — в анкер у верхнего края спирали, уложить по спирали ~1 виток →
   4 витка вокруг вала мотора → дальше по спирали ~1 виток → анкер 2 через пружинку (из ручки) — натяжение «как гитарная струна».
4. Плечо: 4×М4×30 к Hz-барабану (гайки в карманах снизу).
5. V: болт М8×45 через стойку (гайки с двух сторон) → 2×608 в V-барабане → гайка с преднатягом. Тросик так же (4 витка на вал мотора V).
6. Площадка дальномера на V-барабан (3×М3×10). Модуль стяжками: луч по риске, через центр оси V.
7. KY-003 — в карман основания (датчиком вверх, провода вниз через отверстие), магнит — в карман нижнего торца Hz-барабана заподлицо, на клей. Размер магнита: `MAG_D`, `MAG_H` в station.scad → перерендерить base и hz_drum. Если датчик не срабатывает — перевернуть магнит другим полюсом.

## Запуск и контроль (этапы — деньги дальше только если этап пройден)
| Этап | Проверка | Критерий |
|---|---|---|
| 1. Hz-ось | лазерная указка на барабане, стена 5 м; `jog H ±20000` ×20 | разброс точки ≤1 мм (0,011°) |
| 2. Дальномер | `probe` → протокол в config.json; `measure -n 30` по стене 3 м | СКО ≤1 мм, среднее = рулетке ±2 мм (смещение → `cal.d0`) |
| 3. Шаги/оборот | `calrev` ×3 | разброс ≤0,01 % |
| 4. Нуль V | точка на стене: V=+x и через зенит (Hz+180, V=180−x) | `cal.v0 = (V1 + V2 − 180)/2` |
| 5. Комната | `scan --dxf room.dxf` против замера рулеткой с диагоналями (room2dxf.py) | расхождение ≤3 мм |

config.json (рядом со station.py) — только изменённые поля, напр.:
```json
{"laser": {"baud": 19200, "cmd_hex": "…из даташита…", "mode": "ascii", "scale": 1000},
 "steps_per_rev_hz": 87712, "steps_per_rev_v": 58490, "cal": {"d0": 1.8, "v0": 0.03}}
```
Без железа: `python3 station.py scan --sim --dxf test.dxf`.

## Камера (фото стен -> развёртки в масштабе 1 px = 2 мм -> слой ELEVATIONS в DXF)
| Камера | config.json `"camera"` |
|---|---|
| Raspberry Pi Camera Module 3 (рекомендуется) | `{"backend":"rpicam","width":2304,"height":1296,"fx":1700,"fy":1700,"cx":1152,"cy":648,"still_args":["-n","-t","800","--autofocus-mode","manual","--lens-position","0.4"]}` |
| Pi Camera v2 / OV5647 | по умолчанию (1640x1232, fx 1357) |
| Домашняя Wi-Fi IP-камера с RTSP (Tapo/Imou/Ezviz) | `{"backend":"rtsp","rtsp_url":"rtsp://user:pass@IP:554/stream1","width":1920,"height":1080,"fx":800,"fy":800,"cx":960,"cy":540}` |
| USB веб-камера | `{"backend":"v4l2","device":"/dev/video0","width":1920,"height":1080,"fx":1400,"fy":1400,"cx":960,"cy":540}` |
- Фокус и экспозиция — фиксированные (автофокус ломает калибровку). Камера смотрит вдоль луча, крепление — `laser_plate`.
- `offset_mm` = [вправо, вверх, вперёд] от точки пересечения осей до объектива — замерить линейкой.
- Калибровка: лист А4 с чёрным кружком Ø40 на стене 2–4 м, луч в центр кружка (`jog`), `python3 station.py camcal` (35 кадров) → вписать результат.
- Съёмка после скана: `python3 station.py photos --dxf room.dxf` → `room_photos/sheet_*.png` + вставка в DXF (PNG держать рядом с DXF).
- IP-камера: её моторы не используются, камера закреплена на площадке; проверить RTSP: `ffmpeg -rtsp_transport tcp -i <url> -frames:v 1 t.jpg`.

## Компоновка проводов
Pi 3/4 + Uno + понижайка 12→5 В — на Hz-барабане (рядом с плечом, на стойках/стяжках). Через ось Hz проходят только
6 проводов (мотор Hz 4 + питание 12 В 2) свободной петлёй. Шлейф камеры и UART дальномера — короткие, вращаются вместе с Pi.

- Открыть: `http://10.42.0.1:8000` (точка STATION) или `http://station.local:8000` (дома). Планшет: «Экран» = полный экран, «Добавить на главный экран».
- Кнопки: Скан · Фото стен · Стоп · Наводка (Hz/V ±10/1/0,1/0,01°, Замер, Нуль Hz, =0) · Пересчёт (после правки cal в config.json) · Скачать (ZIP).
- План: стены, длины, углы (зелёный — 90±0,3°), H пол–потолок; тап по длине стены → развёртка с фото. Жесты: сдвиг, щипок.
- Проекты: `~/scans/<дата>_<объект>/`: scan.json, room.dxf (с картинками), **room_fusion.dxf** (без облака и картинок — Fusion 360 / мебельные), room_photos/sheet_*.png.
- Без железа: `python3 pi/web.py --sim --port 8000 --dir /tmp/scans`.

## 3D, уровни, неровности, ниши, несколько комнат (room3d.py)
**Авто-нивелир:** MPU6050 (GY-521) на Hz-барабане рядом с осью; I2C: SDA pin 3, SCL pin 5, 3,3V pin 1, GND pin 9.
- `sudo raspi-config` → Interface → I2C → Yes; `sudo apt install python3-smbus`.
- Ось X датчика — по лучу при Hz=0, Z — вверх.
- Проверка знаков (`imu.sign` в config.json): поднять сторону основания по лучу (Hz=0) → «Калибровка» должна дать tilt_y < 0.
- «Калибровка» = 4 положения Hz → наклон штатива (смещение нуля датчика исключается). Допуск ±3°, выставлять по пузырьку.
- «Индекс V» (один раз, сохраняется в config.json) = 8 пар замеров лево/право через зенит по потолку и полу.

**Скан:** профиль 0,5° → прямые и дуги → уточнение кромок бисекцией (0,002°) → ниши и выступы → поиск их верха и низа по V → пол и потолок → 3D.

**Уровень:** луч держит заданную высоту Z (от пола в начале координат) по кругу или от метки «Начало» до «Конец». Выдаёт дуги R / длину / хорду, ниши, выступы.

**Неровности:**
- Стена: сетка (шаг 50–100 мм) → зазор до вертикальной плоскости по самой выступающей точке, плоскостность, отклонение от вертикали.
- Пол вдоль стены: подъём ножек от высшей точки.
- PNG с цифрами в каждой ячейке + цветная сетка в 3D.

**Стоянки (дом, лестница):**
1. На стоянке: Калибровка → Скан.
2. Наклеить ≥3 марки, видимые и со старой, и с новой точки. Замерить каждую: «Опорная т.» с номером (луч в центр марки, «Наводка» шаг 0,01°).
3. «Новая стоянка» → перенести станцию → Калибровка → те же марки с теми же номерами → Скан.
4. Привязка: поворот вокруг Z + сдвиг XYZ, СКО по маркам показано в таблице «Стоянки». Норма: ≤1 мм; >2 мм — перемерить марку.

**Файлы проекта:**
- room.dxf: WALLS (с дугами), DIM, ANGLES, HEIGHTS, FEATURES, LEVELS, SURFACES, REFS, CLOUD, MODEL3D (3DFACE).
- room_fusion.dxf: без облака точек и 3D.
- room.obj (с цветом) и room.stl: Fusion 360 → Insert → Insert Mesh.
- model.json, surface_*.png.
- Начало координат: угол A на полу; X — вдоль самой длинной прямой стены первой стоянки; Z — вверх.

## Без штатива (малое помещение, один замер)
- Установка: **Штатив / Пол (ножки) / Стол-столешница** — список вверху экрана, затем «Нивелир» (допуск ±5°).
- **Пол / стол:**
  1. Пол и потолок сначала (свой корпус ближе 400 мм отсекается; на столе отсекается столешница).
  2. Профиль «по уровню» на 1000 мм от пола, шаг 1°.
  3. Ниши — по кромкам проёма на плоскости стены (с низкой точки дно ниши не видно, проём — видно).
- **Пол не виден (со стола):** навести на пол → «Пол ⊥» (1 точка — горизонт, ≥3 — плоскость).
- **Быстрый замер без скана:** навести → «Точка +» → таблица.
  - Между точками: L, L по горизонтали, ΔH, уклон; от первой до последней.
  - Для ≥3 точек: площадь и периметр.
  - В DXF — слой QUICK. «Ур. 0» + «Замер» — ΔH от выбранной точки.

## v3 КОМПАКТ (актуальная версия; заменяет «Корпус v2») — как DISTO 3D
**Компоновка:**
- Голова по центру: дальномер + камера + MPU6050, окно из оргстекла 32x38x2. Голова — в вилке из двух закрытых башен.
- Левая башня: блин-мотор V + барабан V. Правая: Pi 3 (или Zero 2 W) + Nano + 2 драйвера.
- Основание: круглый корпус с мотором Hz, выключателем, предохранителем, отсечкой, INA219.
- Полая ось Hz (труба 30x2): голова опускается до V=-90° → **лазерный отвес** строго под станцию.
  Через ту же трубу идут 6 проводов. Кнопка «Отвес ⊥»: высота оси над опорой; на полу — точка пола.
- Аккумулятор Festool висит снизу на адаптере и смещён от оси (луч отвеса проходит в 9 мм от него).
  Ног 3, наклонные, конусы М8. Штатив — гайка 1/4" в 42 мм от оси (отвес и на штативе свободен).

**Размеры:**
- 222x222 мм, высота 278 мм, луч на 242 мм над опорой, масса ≈2,1 кг.
- Центр масс на 129 мм над опорой, ход при вращении ±3 мм. Опрокидывание при 21° (4,0 Ач — 23°).
- Вниз луч доходит до -45° (дальше мешает барабан); исключение — отвес -90°.

**Печать — Bambu Lab P1S** (PETG HF, текстурный PEI, 0,2 мм, 4 стенки, гироид 35 %, всё без поддержек):
| Стол | Детали | Ориентация |
|---|---|---|
| 1 | base 222x222x112 | плитой вниз, ноги вверх |
| 2 | alidade 156x104x98, housing 154x132x35 | алидада основанием вниз; корпус крышкой вниз |
| 3 | hz_drum, v_drum, head, head_lid, pod_lid_l, pod_lid_r, collar | барабаны плоско (канавка без поддержек), голова дном вниз |
| 4 | foot x3 — **TPU 95A** с внешней катушки (не через AMS) | основанием вниз |

- AMS: крышки башен и головы можно цветом. Посадки 6806 (Ø42,15), 608 (Ø22,15) и трубы (Ø30,25) — сначала тестовое кольцо.
- Сборка: труба 30x2 длиной 55 мм зажата 2xM4 в хомуте корпуса.
  - Барабан на 2x6806 сидит на трубе. Сверху хомут collar с преднатягом (М3).
  - Алидада 4xM4 к барабану (гайки снизу).
  - Голова на цапфах М8 в 608: левая — болт через барабан V и внутреннее кольцо (зажим), правая — болт М8x20.
  - Тросики как раньше; на валы блинов — латунные втулки.

**Электроника в башне:**
- Nano: STEP D2/D3, DIR D5/D6, EN D8, Холл D9 (пины как у CNC Shield — прошивка та же). Драйверы TMC2209 или A4988 на макетке 50x70.
- Питание 18 В на VMOT, Pi от понижайки 5 В.
- Кабели головы (лазер UART, шлейф CSI 30 см, I2C MPU6050) — через щель под осью в правой башне, петля ±100°.
- `config.json`: `"steps_per_rev_hz": 59323, "steps_per_rev_v": 34708` (уточнить calrev), `"base_drop_mm": 242`.

**Ноль V и нивелир:**
- MPU6050 в голове: при включении станция сама находит горизонт луча (раньше после включения V был неизвестен).
- «Нивелир» = ноль V → 4 положения Hz (наклон) → снова ноль V с учётом наклона.
- «Индекс V» (один раз) — через зенит по потолку, хранится в config.json (это смещение нуля акселерометра).

## v4 ЛЁГКАЯ: встроенный аккумулятор 3S 21700, 2 мотора-«блина», без ног
**Размеры:** 198x160, высота 188 мм, луч на 152 мм над опорой, масса ≈1,5 кг. Центр масс 83 мм над опорой, опрокидывание при 25°.

**Аккумулятор:**
- 3 банки 21700 (Molicel P45B / Samsung 50S, 4500–5000 мА·ч) последовательно, 3S1P: 11,1 В, ≈50 Вт·ч → ≈4,5–5 ч работы.
- Банки — только **с приваренными лепестками** (не паять по корпусу банки). Лежат в корпусе Hz напротив мотора, на 2 ложементах дна + вспененный скотч.
- Плата BMS 3S (с балансировкой, 10–20 А) — у оси со стороны +Y. Она же отсечка разряда: XH-M609 больше не нужна.
- **Цепь:** банки → BMS → предохранитель 5 А (в проводе) → выключатель KCD1 (стенка -Y) → 2 провода через трубу оси на голову.
- **В правой башне:** понижайка mini560 5 В 5 А → Pi 4; VMOT драйверов — напрямую 9–12,6 В; INA219 — напряжение на экран.
- **Зарядка:** гнездо DC 5,5/2,1 на стенке -Y → BMS (P+/P-), зарядник 12,6 В 2 А (≈2,5 ч).
- **Индикатор заряда:** модуль 3S на 4 светодиода, окно 30x6 на стенке отсека (+Y). Питание — после выключателя: в выключенном состоянии не разряжает.
- **ZK-4KX:** лабораторный блок питания для проверок на столе (в станцию не ставится).

**Нуль Hz — TCRT5000 (ваш):**

## Вынос проекта (как Leica iCON) — `pi/layout.py`, панель «Вынос проекта» в пульте
**Кадр проекта** = кадр `room_fusion.dxf` (начало — угол A на полу, X вдоль A-B). Проект кухни рисовать в Fusion поверх него, начало не сдвигать.

**DXF проекта → точки и линии:**
- Точки: POINT, CIRCLE (центр, подпись Ø), блоки (INSERT). Линии: LINE, полилинии (дуги — хордой). Подпись — ближайший TEXT ≤200 мм.
- Слои выбираются галочками; наши служебные слои (WALLS, DIM…) пропускаются.
- **План:** X, Y из DXF; высота — Z из DXF / на полу / на потолке / H от пола.
- **Развёртка стены:** X DXF — от выбранного угла вдоль стены (по умолчанию левый, если смотреть из комнаты), Y DXF — высота от пола в этом углу.

**Кнопки:**
| Кнопка | Что делает |
|---|---|
| Навести ⦿ (◀ ▶ — соседняя точка; двойной тап по строке) | луч точно на точку проекта **по реальной поверхности**: замер → поправка вдоль стены → повтор (до 4 раз, остаток ≤0,3 мм). Показывает, насколько стена/пол выступает или утоплена против проекта |
| Привязать | «луч сейчас на известной точке»: номер точки из списка или X Y Z |
| Своб. станция | положение станции по ≥2 известным точкам: опорные марки прошлых стоянок (замерить «Опорная т.» с тем же номером) + привязки. СКО и ошибка каждой точки |
| Линия… | лазер ходит туда-обратно по линии DXF или по уровню на стене (H от пола в левом углу) до «Стоп»; «точно» — замер в каждой точке по реальной стене |
| Проверка ст. | наклон (компенсатор) + повторный замер марок теми же углами: ΔD > 2 мм или наклон > 0,03° → «СДВИГ» |
| Проект—факт | стены проекта (слой DXF) против скана: смещение концов стены (+ = выступает в комнату), угол; `compare.dxf` (PROJECT / FACT / DEVIATION) |

**Компенсатор:** после «Калибровки» MPU6050 каждые 25 замеров сверяется с наклоном из калибровки; ушёл > 0,03° → замер останавливается, красная плашка. Настройка — `tilt_watch` в config.json.

**Лазер-указка:** модуль — `laser.pointer_hex` / `pointer_off_hex` (команды из даташита); ручной дальномер — одно нажатие кнопки.

**Ограничения:** луч не ниже −45° (корпус) — точки на полу ближе ≈1,4 м от станции на штативе не выносятся, нужна другая стоянка. Под острым углом к поверхности (>70° к нормали) точность хуже — пульт предупреждает.

**Симуляция (`tools/t4.py`):**
- стена: 7 отверстий ≤0,44 мм вдоль стены, ≤0,38 мм по высоте;
- пол: ≤0,8 мм;
- свободная станция по 3 маркам: СКО 0,6 мм, вынос с неё ≤0,5 мм;
- толчок 0,1° пойман компенсатором, сдвиг 3 мм — проверкой стоянки;
- проект—факт: стена, сдвинутая в проекте на 10 мм → +12 мм (10 + выпуклость стены), остальные ±0,8 мм.

## Шнур привода: масштаб и проскальзывание (метка нуля Hz)
- «Калибровка» теперь сначала делает 3 поиска метки TCRT5000: 2 полных оборота = точные шаги на оборот Hz (износ/вытяжка шнура меняют передаточное число — находится каждый раз). Ноль Hz — по метке.
- После «Скан» — контроль: доезд до метки, расхождение счётчика > 0,02° → красная плашка «проскальзывание шнура».
- После перезапуска программы/Arduino станция находит метку заново → калибровка стоянки остаётся верной.
- Без датчика метки: `"hz_mark": false` в config.json.
- Симуляция: шнур длиннее на 0,4 % → без метки ошибка углов комнаты до 98 мм, с меткой ≤2,7 мм; проскальзывание 0,1° поймано.

## Шнур: кассета быстрой замены и ресурс
**Конструкция (Hz, сверху, без инструмента, ~3 мин):**
- Спираль барабана 3,5 витка → ход барабана ±1,5 оборота (шнур закреплён на концах; программа держит барабан в −1,05…+1 оборота).
- Конец A — узел + бусина Ø3–4,5 в кармане (72°), шнур опускается в прорезь 1,4 мм.
- Конец B — петля на **пружине растяжения** в дуговом канале (252°…287°), пружина на крючке. Пружина держит постоянное натяжение и выбирает ползучесть шнура — подтягивать не нужно.
- Оба места открыты сверху между башнями (пластина под головой уменьшена до R47).
- Левая крышка башни (шнур V) — на 4 магнитах 6×3, снимается рукой.

**Кассета Hz (сделать заранее 2–3 шт.):** шнур 0,5 мм ≈1,6 м; на одном конце узел + бусина; на расстоянии **≈1425 мм** от узла — петля Ø5 (точную длину записать после первой сборки: пружина должна растянуться на 10–15 мм).
**Шнур V:** ≈0,6 м, узлы как раньше (крышка на магнитах).

**Замена Hz:**
1. Снять петлю с пружины, вынуть шнур из прорезей и с вала мотора.
2. Узел — в карман A, ~1,75 витка по спирали к мотору, 4 витка на вал мотора, остаток по спирали к B.
3. Петлю — на пружину.
4. «Новый шнур» (пульт, «Наводка») → «Калибровка» (масштаб нового шнура запомнится как исходный).

**Покупки:** плетёнка Vectran 0,5 мм (меньше ползучесть) или Dyneema/PE 0,5 мм; пружины растяжения Ø5–6, проволока 0,6–0,8, длина 25–30 мм (≈1,5 Н/мм, натяжение 15–25 Н); бусины/обжимные трубки Ø3–4; магниты неодимовые 6×3 мм, 8 шт.

**Ресурс (оценка, проверить на железе):**
- Помещение (калибровка + скан): барабан Hz ≈33 оборота, V ≈5 (симуляция). Вынос точки — доли оборота.
- Износ шнура — от перегибов на валу Ø6,5 (отношение D/d ≈13): ориентировочно 10⁵ и больше перегибов → **≈1500 помещений** при заложенном в программу ресурсе 50 000 оборотов (с запасом ×2), шнур V — в несколько раз дольше.
- При 2 помещениях в день — ≈3 года; менять **раз в год** или по сигналу.
- **Сигналы замены (программа сама):** пробег ≥100 % («шнур Hz …%» в строке стоянки); вытяжка/износ > 3000 ppm от нового (утоньшение ≈0,02 мм); проскальзывание > 0,02° после скана.

## Шкив 188T — металлический (точность Hz)
**Почему важно:** смещение (эксцентриситет) шкива относительно оси даёт ошибку угла `e/R·sin(Hz)`: e = 0,05 мм → 0,048° → **≈4 мм на 5 м**; e = 0,01 мм → 0,01° → ≈0,8 мм. Это главный источник ошибки Hz (больше микрошага и дальномера). Венец центрируется **самой осью-трубой** (на ней же сидят подшипники).
**Готового алюминиевого GT2 188T с отверстием 30 мм в продаже нет** (стандартные — до 60–80 зубьев, отверстие 5–8 мм). Заказ по DXF:
| Способ | Точность контура | e (с подгонкой отверстия) | Ошибка на 5 м | Где |
|---|---|---|---|---|
| **Электроэрозия проволокой** (cięcie drutem EDM), одна пластина 8 мм | ±0,005 мм | ≈0,01 | ≈0,8 мм | инструментальные цеха |
| **Фрезеровка ЧПУ** (frezowanie CNC), пластина 8 мм, фреза ≤1 мм | ±0,02 мм | ≈0,01–0,02 | 0,8–1,7 мм | цеха ЧПУ, Xometry |
| **Лазер** (cięcie laserem), 2 пластины по 4 мм | ±0,05 мм | ≈0,03–0,05 | 2,5–4 мм | любая лазерная резка |
| Печать (как было) | ±0,1 мм | 0,05–0,1 | 4–8 мм | — |
**Файлы:** `cad/gt2_188_plate.dxf` — венец (OD 119,18; профиль GT2 2 мм; 188 зубьев; отверстие 30,25; 6×Ø3,3 на R46), `cad/gt2_188_flange.dxf` — реборда Ø123,2, 2 шт. по 1,5 мм (верхняя — белая метка нуля).
**В заказе указать:** материал Al 6061/7075 или нержавейка; толщина венца 8 мм (или 2×4); **отверстие Ø30 H7 под фактический диаметр трубы** (измерить штангенциркулем, посадка без зазора); биение зубьев относительно отверстия ≤0,02 мм.
**Труба оси:** калиброванная (precyzyjna, h8/h9) 30×2 — от её точности зависят и подшипники, и соосность шкива.
**Шкив мотора 16T:** фирменный с малым биением (≤0,02 мм): его биение даёт до 1,7 мм на 5 м (повторяется 11,75 раза за оборот).
В `station.scad`: `PULLEY = "metal"` (по умолчанию; ступица дна под 6 винтов М3 через латунные вставки) | `"print"`.

## Только печать: шкив 192T и самокалибровка круга Hz (актуально)
**Шкив печатается заодно с дном** (`PULLEY = "print"`): зубья и гнездо трубы — в одних слоях → соосны с точностью принтера. Труба — **на натяге, без зажимных винтов** (винты сдвигают трубу в зазоре = эксцентриситет).
- Подбор натяга: напечатать `fit_rings` (4 кольца: Ø −0,15 / −0,05 / +0,05 / +0,15 мм, метки 1–4 риски), выбрать кольцо, которое надевается на трубу туго, рукой с усилием; значение в `T_FIT`. Трубу запрессовать (можно каплю циакрина).
- Печать дна: PLA или PETG, слой 0,12, внешний периметр первым, шов — «на заднем крае» не на зубьях (Bambu: Seam = Back/Aligned), скорость внешнего периметра ≤60 мм/с, без «слоновьей ноги» (калибровка первого слоя).
- **Передача ровно 1:12** (192/16): ротор мотора при одном и том же Hz всегда в той же фазе → биение шкива мотора — тоже функция угла и калибруется. Ремень GT2-6 **400 мм** (самый ходовой), мотор на R73,3 (пазы ±2 мм). 76 800 шагов/оборот.

**Самокалибровка круга Hz (раз после сборки, потом — раз в год или после разборки дна):**
1. Станция в комнате с ≥3 прямыми стенами длиннее 0,6 м (обычная комната).
2. «Наводка» → «Круг Hz +» (калибровка наклона + профиль по кругу, ~2–3 мин).
3. Повернуть **станцию целиком** на ~90° (на штативе — поворот головки штатива; на полу — переставить), «Круг Hz +». Всего **4 положения** (≈0°, 90°, 180°, 270°, точность поворота не важна).
4. «Круг Hz =» — расчёт, поправка сохраняется в `config.json` (`hz_err`) и действует во всех замерах.
- Находит: эксцентриситет и эллипс шкива 192T (гармоники 1–3) и биение шкива мотора (12-я).
- Симуляция (`tools/t6.py`, шкив с e=0,08 мм + эллипс + биение 16T 0,027 мм): ошибка круга ±0,117° → **±0,016°**; углы комнаты max 6,3 → 3,6 мм (среднее 1,6 → 1,0).
- Металлический венец по DXF (`gt2_192_plate.dxf`) — по-прежнему возможен (`PULLEY = "metal"`), но с самокалибровкой не обязателен.
