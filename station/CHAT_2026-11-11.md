# ЧАТ 2026-11-11 — станция замеров: продолжение (перенос на ПК)

Файл для продолжения в любой сессии Claude Code / Claude на ПК. Вставить в чат: «Прочитай station/CHAT_2026-11-11.md, station/HANDOFF.md и продолжай».

## Контекст
- Репозиторий: github.com/AndriiRy/xxl, папка `station/`. Ветка: `claude/room-measurement-scanner-w9upys` (содержит всю работу прошлой сессии «Сканер замеров мебели», ветка `claude/dreamy-hawking-fu5wsa`, коммит e973571, + этот чат).
- Начинать с `station/HANDOFF.md`, затем `station/BUILD.md`.
- Сводка проекта: самодельная полярная станция (Hz, V, D) как Leica DISTO 3D: Pi 4 + Nano + 2×NEMA17 + TMC2209, ремень GT2 (Hz без ограничения), шнур V, АКБ 3S 21700, пульт в браузере (Wi-Fi STATION, 10.42.0.1:8000). Ничего ещё не собрано на железе.

## Ход чата
1. **«Продолжим сессию»** → найдена прошлая работа, ветка перемотана на неё и запушена.
2. **«Список покупок для польских сайтов, наверх»** → в начало `BUILD.md` добавлен раздел «🛒 СПИСОК ПОКУПОК» по магазинам; старые дубли заменены ссылкой; в `HANDOFF.md` — указатель.
3. **Фото: Bosch GLM 40 уже есть** — 3 601 K72 900, выпуск 04/2024, Made in Malaysia, 2×AAA. Убран из покупок, итог ≈940 zł.
4. **Фото: Allegro, Raspberry Pi Camera Module 3 Standard 12MP IMX708, 139,65 zł** — подходит (Standard, не Wide/NoIR; `fx 1700` под неё). Оранжевый шлейф Standard–Mini — только Pi 5; для Pi 4 — белый Standard–Standard, нужен ≥300 мм (уточнить длину у продавца, иначе докупить ≈15 zł).
5. **«Найди всё на Allegro у одного продавца»** → из облака allegro.pl (а также kamami.pl, tme.eu, kaufland.pl) недоступен — шлюз 403. Добавлены ссылки поиска Allegro по всем позициям. Botland покрывает только часть (см. ниже).
6. **«Перенеси чат на компьютер»** → `claude --teleport` (шаги ниже) и этот файл.

## Что делать дальше
1. **Bosch GLM 40:** вскрыть (батарейки вынуть; винты в отсеке/под наклейками, дальше защёлки), фото платы с двух сторон с линейкой, крупно маркировку МК и площадки/разъёмы 4–7 конт., размеры платы с оптикой, положение окна лазера и линзы приёмника. Экземпляр 2024 г. — возможна новая ревизия, протокол сверить по плате. Случайные команды в порт не слать (есть команды прошивки).
2. Поиск порта (когда будет Pi): `python3 station.py sniff 9600 --send "c0 40 00 ee"` по очереди на площадках через 1 кОм; ответ `c0 40 00 ee 00 04 xx xx xx xx yy` = порт найден → `config.json`: `"laser": {"preset": "bosch", "trigger_gpio": 17}` → калибровка `d0`.
3. По фото платы — перерисовать голову в `cad/station.scad` (прибор целиком 105×45×24 в сечение 31×55 не входит).
4. Покупки — по списку ниже; один продавец на Allegro: открыть редкую позицию (NEMA17 плоский / ремень GT2 400 замкнутый / 6806) → продавец электроники/3D → «Inne przedmioty sprzedającego» → искать остальное.
5. Автопоиск на Allegro: локальная сессия + расширение Claude in Chrome → `/chrome` → «найди всё на Allegro у одного продавца».

## Перенос сессии на ПК
```
# Windows PowerShell:  irm https://claude.ai/install.ps1 | iex
# Mac/Linux:           curl -fsSL https://claude.ai/install.sh | bash
git clone https://github.com/AndriiRy/xxl
cd xxl
claude --teleport        # выбрать «Сканер замеров помещения»; если откажет — git stash и повторить
```
Без teleport: `git checkout claude/room-measurement-scanner-w9upys`, затем `claude` и попросить прочитать этот файл.
