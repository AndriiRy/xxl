# HANDOFF — станция замеров помещений (аналог Leica DISTO 3D, самосборка)

Документ для продолжения работы в новой сессии Claude Code. Начинать с него, затем `BUILD.md` (разделы «v4 ЛЁГКАЯ» — электрика и «v5 СКРУГЛЁННАЯ» — корпус).

## Пользователь
- Мебельщик (кухни), Польша. Цены — zł, покупки — Allegro. Язык — русский.
- Стиль ответов: плотно, тезисно, без приветствий, заключений и общих советов.
- Принтер: Bambu Lab P1S Combo (AMS, стол 256³). Печать PETG.

## Цель
Дешёвая полярная станция (Hz, V, D) на штативе/на полу/на столе, погрешность ≤3 мм:
- 3D-модель помещения XYZ, экспорт DXF/OBJ/STL для Fusion 360;
- углы стен, высоты пола/потолка, ниши/выступы (автоматически), полукруглые выступы по уровню (как DISTO);
- карты неровностей стены и пола под кухню, нивелир, отвес;
- несколько стоянок (весь дом, винтовая лестница) — сшивка по опорным маркам без потери уровней;
- фото стен → развёртки в масштабе;
- всё считает Pi 4, пульт — браузер планшета/телефона по Wi-Fi (точка доступа STATION, 10.42.0.1).

## Инвентарь пользователя (по фото)
Pi 4 (алюм. корпус с вентилятором), БП JustPi, microSD 32/16, Arduino Nano, NEMA17 42HN40 (большой — решено заменить),
MPU6050, TCRT5000 (используется как нуль Hz), KY-010, LM393 щелевой, KY-035 Холл, SSD1306 (решено не ставить), LCD1602,
DWIN DMG85480F050 5″, энкодер C38S6G5-600B-G24N, клавиатуры 4x4/4x5, ZK-4KX (останется лабораторным БП), ESP8266, преобразователь уровней, макетки.

## Текущая версия — v5 СКРУГЛЁННАЯ (электрика v4)
- 198x160x196 мм, луч на 152 мм над опорой, 1,5 кг, ЦМ 83 мм, опрокидывание 24°. Все наружные кромки скруглены (R6 корпус, R8 башни, R3 голова), ножки с шариком.
- 2x плоский NEMA17 17HS4023; тросиковый привод: Hz барабан Ø120 (1:18,5, 59323 шаг/об), V барабан Ø70 (1:10,8, 34708 шаг/об), 1/16 микрошаг.
- Полая ось Hz: труба Al 30x2 на 2x 6806; лазерный отвес через трубу и отверстие Ø16 в дне.
- Голова (дальномер + камера + MPU6050) по центру между двумя башнями, может смотреть почти вертикально вниз (V до −90° для отвеса).
- Аккумулятор встроен: 3S1P 21700 + BMS 3S, предохранитель 5 А, KCD1, гнездо DC 5,5/2,1 (зарядник 12,6 В 2 А), индикатор 3S на 4 LED. Без OLED.
- 3 ножки-конуса прямо под дном: FEET [[40,68],[40,−68],[−98,0]]; гайка 1/4″ под штатив в (42,0).
- Nano + 2x A4988/TMC2209, mini560 5 В, INA219 — в правой башне; Pi 4 без корпуса.
- Ориентировочная закупка ≈280–360 zł (+ камера, + дальномер при необходимости). Список — в `BUILD.md`.

## История решений (кратко)
1. Скан 2D → DXF (room2dxf/scan2dxf) → полноценный 3D (room3d.py).
2. Веб-пульт на Pi (stdlib http.server) вместо отдельного монитора.
3. v2: Festool 18V + ножки → v3 компакт (голова по центру как DISTO) → v4: встроенные 21700, плоские моторы, без ног и OLED.

## Структура
- `cad/station.scad` — параметрический корпус OpenSCAD. Детали: `base housing hz_drum alidade pod_lid_l pod_lid_r head head_lid v_drum collar foot assembly down`.
  Рендер: `openscad -D 'part="base"' -o base.stl cad/station.scad`. Готовые STL — в `cad/`.
- `cad/com.py` — центр масс/устойчивость, подбор ножек (`python3 cad/com.py -v`).
- `firmware/station/station.ino` — Nano: STEP D2/D3, DIR D5/D6, EN D8, нуль D9 (LOW). Команды по Serial, в т.ч. `S <hz> <v>`.
- `pi/station.py` — ядро: привод, дальномер, IMU, авто-нивелирование (4 положения Hz), индекс V (двумя кругами по потолку), отвес, сканы, трасса уровня, сетка неровностей, батарея.
- `pi/room3d.py` — анализ: профили → линии/дуги, углы, ниши/выступы, пол/потолок (робастная плоскость), сшивка стоянок (4 DOF), сетки неровностей, экспорт DXF/OBJ/STL/JSON.
- `pi/web.py` + `pi/web/index.html` — пульт (план SVG, 3D canvas, наводка, быстрые замеры P2P, вынос проекта).
- `pi/cadm.py` — чертёж при замере (как Flexijet): точка/стена/ребро/плоскость/окружность, пересечение, расстояние, угол -> cad.dxf.
- `pi/worktop.py` — шаблон столешницы (как Flexijet Stone): трасса по уровню -> контур по стенам, вырезы -> worktop.dxf.
- `pi/layout.py` — вынос проекта как Leica iCON: DXF → точки/линии на стене/полу/потолке, итерационный вынос по реальной поверхности, свободная станция, проект—факт. В `station.py` — компенсатор (контроль наклона MPU6050 каждые 25 замеров, `Moved`) и лазер-указка.
- `pi/sim_room.py` — виртуальная кухня для `--sim` (ниша, дуга R350, пилястра, неровная стена, наклонные пол/потолок, ошибки штатива/IMU).
- `pi/photos.py` — фото стен → развёртки. `pi/setup_web.sh` — точка доступа + systemd.
- `tools/t1.py … t5.py` — тесты на симуляции (t4 — вынос проекта, свободная станция, компенсатор, проект—факт; t5 — масштаб шнура по метке, проскальзывание, чертёж при замере, столешница); `tools/simmap.py` — проект↔мир для тестов; `tools/render.py` — PNG из STL; `tools/shot*.js` — скриншоты UI (Playwright); `tools/stub/` — заглушки для компиляции .ino на ПК.
- `docs/img/` — рендер v4 и скриншоты пульта.

## Запуск на ПК (симуляция)
```
pip install numpy matplotlib
cd station/pi
python3 web.py --sim --port 8011 --dir ~/scans      # открыть http://localhost:8011
python3 ../tools/t1.py "$PWD" /tmp/wt1               # скан на штативе
python3 ../tools/t2.py "$PWD" /tmp/wt1               # опорные марки, уровень 900, неровности, 2-я стоянка (после t1)
python3 ../tools/t3.py "$PWD" /tmp/wt3               # режим «на полу» + быстрый P2P
python3 ../tools/t4.py "$PWD" /tmp/wt4               # вынос проекта (iCON), свободная станция, компенсатор
python3 ../tools/t5.py "$PWD" /tmp/wt5               # шнур (масштаб/проскальзывание), чертёж при замере, столешница
```
`config.json` создаётся рядом со station.py; в режиме sim не перезаписывается.

## Результаты симуляции
- t5: шнур +0,4 % — без метки углы до 98 мм, с меткой ≤2,7 мм; угол комнаты по 2 стенам ≈3 мм (опорная стена выпуклая); столешница ±1,7 мм.
- Вынос (t4): стена ≤0,44 мм, пол ≤0,8 мм; свободная станция по 3 маркам СКО 0,6 мм; толчок 0,1° и сдвиг 3 мм пойманы.
- Штатив: углы ±1 мм, углы стен ±0,1°, высоты ±1 мм. Ниша 800x1200, низ 842; дуга R350 (1099–1100); пилястра 400.
- 2-я стоянка: RMS сшивки 0,26–0,6 мм, углы ≤1,4 мм. Уровень 900: R349, ниша 802. Стена: плоскостность 6,5 мм, завал +2,3 мм/м; пол 1,8 мм/м.
- v4 на полу (наклон 1,8/−1,6°): наклон найден точно, индекс V 0,229° (истина 0,229°), отвес 152,3 мм, углы ±1,2 мм, P2P 4122,3 vs 4122,4.

## Открытые вопросы / следующие шаги
1. **Модель дальномера** (главный риск): нужна модель или фото платы ручного дальномера, либо покупка модуля с UART. От этого зависят `laser.cmd_hex` / `laser.trigger_gpio` в config.json и крепление в голове.
2. Финальный выбор банок (21700 P45B/50S или 18650 — тогда поменять `CELL_D`/`CELL_L` в station.scad).
3. Ничего не проверено на железе: печать тестовых колец посадок (6806 Ø42,15, 608 Ø22,15, труба Ø30,25), калибровка steps_per_rev, проверка индекса V и отвеса.
4. alidade.stl даёт предупреждения non-manifold (Bambu Studio чинит автоматически) — можно поправить в scad.
5. Камера: Pi Camera Module 3 или RTSP-камера; калибровка `camera` в config.json.
6. Сделано по мотивам Leica iCON: вынос точек/линий из DXF, лазерная линия, свободная станция, проверка стоянки, компенсатор, проект—факт (BUILD.md, раздел «Вынос проекта»). Не сделано: автонаведение на марку ArUco камерой (нужны камера и OpenCV), лазер-указка — команды зависят от модели дальномера.
7. Исправлено: после перезапуска программы ноль V искался без наклона стоянки (ошибка V до величины наклона) — теперь калибровка стоянки восстанавливается при подключении; карта неровностей пола больше не падает на точках под станцией (пропускает их).
8. Исправлено: стык кругового профиля — в дальней точке (вершине); короткая прямая у конца дуги сливается с дугой (иначе от сдвига сетки замеров появлялся лишний угол).
9. Шнур: масштаб Hz по метке при каждой калибровке, контроль проскальзывания после скана, ноль Hz по метке после перезапуска. Масштаб V пока только из config (`steps_per_rev_v`) — с SCL3300 можно мерить по наклонам.
